# ASIC_CD2
Criação de um ASIC((Circuito Integrado de Aplicação Específica) para a disicplina Circuitos Digitais II.


Problema a ser resolvido. Leia as dimensões das arestas de um prisma retangular reto por meio da porta de entrada DataIn.
Calcule o somatório de todas as suas arestas e apresente o resultado na porta de saída DataOut.
